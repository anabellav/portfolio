# Anabella Volpi — portfolio

A single-page portfolio in plain HTML, CSS and JavaScript. No dependencies or build step.

## Preview

Open `index.html` directly in your browser, or run `python3 -m http.server 8000 --bind 127.0.0.1` from this folder and visit http://127.0.0.1:8000.

## Edit

- `index.html`: navigation, introduction, projects and contact content.
- `styles.css`: colours, typography, spacing and mobile layout.
- `script.js`: automatically updates the footer year.

Replace the labelled project image and description placeholders with your own content. Replace the contact placeholder with your email address and a `mailto:` link. The About navigation links to the introduction; project cards are ready for future case studies.

This project is local only and has not been published.
