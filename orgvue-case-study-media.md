# Orgvue case-study source and assets

Current source: [ODS - Orgvue, Figma 252:12105](https://www.figma.com/design/UycHJSZDRbeKbIfL2ynruU/Portfolio?node-id=252-12105), 1440 × 7975px.

The existing route is `orgvue-design-system.html`. Page-specific styles and section navigation remain in `orgvue-case-study.css` and `orgvue-case-study.js`. Shared portfolio files and recording demos are unchanged.

## Design measurements

- Content: 980px, centred (230px desktop gutters).
- Reading width: 692px.
- Headings: local Lato Regular; hero 52px / 62.4px; section headings 44px / 52.8px.
- Body: Open Sans Regular, 16px / 28px.
- Page: white, matching the latest source frame. Old gradient bands are removed.
- Each main section has 64px vertical padding at desktop, with responsive reductions.
- The source frame has no resting project-menu band. The existing section-navigation behaviour is retained as a sticky menu revealed after the overview, without adding vertical space to the source layout.

The three priority icons and three progression icons are individual SVG exports from the same frame. Article headings, all editorial copy, metadata and the three feedback quotes remain HTML. Product UI and documentation text within approved visuals remain part of those image assets.

No artwork or case-study copy is missing for this frame. The quoted feedback is transcribed verbatim from Figma, without invented attribution.

The Problem stage uses `assets/videos/old-filters-demo.mp4`, generated by `scripts/record-table-filters.py` using Playwright recordVideo. A WebM export and matching source-page poster are also available. Both video files are 1760 × 1116, preserving the natural 880 × 558 demo aspect ratio without spatial cropping, padding or resizing. The video plays muted, looping and inline, with manual playback for reduced-motion users. Previous recordings are retained unchanged.

The What I considered stage uses `assets/videos/new-filters-demo.mp4`, exported by the same Playwright recorder with `--demo new`. It has the same 1760 × 1116 frame and responsive video styling as the old filters clip. The recording shows live search, a date range, the applied-filter count and clearing filters. WebM, poster, decoded review frame and verification report are also available. The Outcome documentation visual remains static.

Automated recording setup and verification are documented in `table-filters-demo-recording.md` and `table-filters-after-demo-recording.md`.
